# Plataforma de Colaboração com Chat em Tempo Real

Projeto de portfolio com stack fullstack moderno:
- Frontend: Vue 3 + Nuxt 3 + TypeScript + Tailwind CSS
- Backend: Express.js + Socket.io
- Banco de dados: MySQL + Prisma ORM

## Objetivo
Construir uma aplicação web completa de gestão colaborativa de projetos, tarefas, equipes e comunicação em tempo real.

## Por que este projeto?
- Demonstra frontend SSR/SPA com Nuxt
- Integra backend REST + realtime
- Mostra modelagem de dados relacional com Prisma
- Exibe boas práticas de autenticação, autorização e validação
- É um ótimo case para portfolio fullstack
